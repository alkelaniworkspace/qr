# Scanwerk – منصة QR Codes فاخرة

منصة SaaS لتصميم أكواد QR وإدارتها، موجّهة لسوق ألمانيا/DACH. واجهة المستخدم بالألماني. التصميم: خلفية غامقة `#0f1113` مع لون ليموني `#d2ff1f`، خط Space Grotesk للعناوين وInter للنص، أزرار ثلاثية الأبعاد، بادجات مايلة، توهج وحركات عند السكرول.
الاسم «Scanwerk» اسم عمل مؤقت، وبتغيّره من مكان واحد: `src/lib/site.ts`.

## التقنيات

Next.js 16 (App Router, Turbopack, `proxy.ts`) · React 19 · Tailwind CSS 4 · Supabase (Auth, Postgres, Storage) · Zod 4 · محرك SVG خاص فينا (`src/lib/qr/render.ts`).

## التشغيل

```bash
npm install
cp .env.example .env.local   # عبّي القيم
npm run dev
```

### Supabase

1. اعمل **مشروع Supabase خاص بالمنصة** (منفصل عن مواقع الزبائن)، ومنطقته `eu-central-1` (فرانكفورت).
2. نفّذ `supabase/migrations/20261114000000_init.sql`، إما بالـ SQL Editor أو بـ `supabase db push`.
3. Authentication → URL Configuration: حط `NEXT_PUBLIC_APP_URL` كـ Site URL، وزيد `…/auth/confirm` على Redirect URLs.
4. لتجرّب أكثر من كود ديناميكي ارفع خطتك يدوياً:
   `update profiles set plan = 'agency' where id = '<user-id>';`

### الدومين القصير (قرار مهم)

الرابط اللي بينطبع جوّا الكود الديناميكي هو `NEXT_PUBLIC_SHORT_URL/<slug>`، وإذا الإعداد فاضي بيصير `NEXT_PUBLIC_APP_URL/r/<slug>`.
**قرّر الدومين قبل ما تطبع أول كود حقيقي**، لأن الأكواد المطبوعة ما بيتغيّر فيها شي بعدين. وجّه الدومين القصير على نفس النشر على Vercel، والـ proxy بيتكفّل بالباقي.

## التحديث: استوديو بالخطوات بدون تسجيل دخول

- **/studio**: أربع خطوات (النوع ← المحتوى ← التصميم ← الطباعة والتحميل)، اختيار النوع ينقلك تلقائياً للخطوة التالية.
- **بدون حساب**: صفحات الجوال (منيو، موقع مصغّر، بطاقة، روابط، كوبون…) مضغوطة داخل الكود نفسه (`/v#...`) فلا تحتاج قاعدة بيانات. الأكواد تُحفظ في المتصفح ضمن **/codes**.
- **تقييم Google**: الصق رابط المكان من خرائط Google ← يُولَّد رابط `writereview?placeid=...` مباشرة. لنتائج مضمونة أضف `GOOGLE_MAPS_API_KEY` (Places API New) في Vercel.
- **استوديو الطباعة**: A6, A5, A4, A3, A2, A1, A0, DL, مربع، بطاقة، ستيكر، ومقاس مخصص بالمليمتر، عمودي/أفقي، هامش قص 3 مم، 10 قوالب و6 لوحات ألوان. التصدير PDF متجهي بالمقاس الدقيق أو PNG بدقة 150/300 dpi.
- **الألوان**: أحمر رماني/عنابي `#d42a4e` مع كحلي `#1f3c88` وذهبي `#e9b949`، و18 تصميماً جاهزاً للكود.
